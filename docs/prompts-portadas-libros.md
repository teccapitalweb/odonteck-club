# Portadas de libros — OdonTeck Club

Prompts para generar portadas de libro en **Flow (Nano Banana Pro)**.

## Configuración en Flow
- **Proporción: 2:3 vertical** (formato libro)
- **x2** variantes por portada
- Guardar con nombre corto: `portada-cirugia-bucal`, `portada-oclusion`, etc.
- El **título y autor se agregarán después** con overlay en la plataforma.

> Estilo: editorial médico premium, colores sofisticados, composición limpia con espacio para texto superpuesto. Cada portada tiene una paleta distinta para diferenciarlas en la biblioteca digital.

## Tips generales
- Si alguna portada sale con texto o logos a pesar del prompt, regenera con x2.
- Después de generar, recorta si es necesario para que el espacio de título quede limpio.
- Para convertir a WebP usa el mismo script de siempre: `quality=82, method=6, max_width=800` (portadas de libro no necesitan más de 800px de ancho).
- El título, autor y año se sobreponen con CSS en la plataforma (no los pongas en la imagen).

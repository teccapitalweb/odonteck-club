# Cuadernillos visuales OdonCoins

## Estado

Colección de quince propuestas originales. Sus cubiertas son arte de apoyo al aprendizaje: no contienen texto, no son diagramas diagnósticos y no sustituyen criterio profesional. Cada recompensa está registrada como `proximamente`; por diseño no se puede canjear ni descontar OdonCoins.

## Regla de activación

Para cambiar una pieza a disponible se requieren, en este orden:

1. Un guion clínico con fuentes y fecha de revisión.
2. Revisión y aprobación firmada por un odontólogo responsable.
3. Texto compuesto fuera de la imagen, con contraste, fuentes y atribuciones verificadas.
4. PDF accesible probado en móvil, escritorio e impresión.
5. Archivo privado entregable y material publicado mediante el flujo administrativo.
6. Confirmar `revisionProfesional: true`, entrega y acceso antes de habilitar el canje.

No se permite activar por el solo hecho de contar con una cubierta o con texto generado.

## Procedencia

Las ilustraciones fueron generadas para esta colección como arte original sin logotipos, texto, marcas ni datos de pacientes. Las fuentes del futuro contenido editorial se deben registrar en el expediente de revisión de cada PDF; no se reutilizan PDFs ni diagramas de terceros por semejanza.

# Prompts para Rompecabezas Clínicos OdonTeck · Formato 3:4 (1080×1440)

Estos **18 prompts** (uno para el rompecabezas de cada uno de los 18 cursos del catálogo) están diseñados específicamente para funcionar como **rompecabezas visuales de 6 piezas (2 columnas × 3 filas)** en proporción vertical **3:4**:

- **Sin texto ni logotipos** (para que ninguna pieza quede con letras cortadas).
- **Composición en 3 niveles verticales claros (Arriba / Centro / Abajo)** y contraste izquierda–derecha para que el alumno identifique de inmediato dónde va cada pieza al armarlo.
- **Paleta OdonTeck:** azul marino (`#0E2747`), turquesa clínico (`#22D3C5`), blanco limpio y acero quirúrgico, sin pacientes identificables ni sangre.

Donde guardarlas cuando las generes:
`public/juegos/rompecabezas/puzzle-01.webp` hasta `puzzle-18.webp` (o `.png`, yo las conecto en cuanto me las pases).

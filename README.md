# OdonTeck Club

Membresía de OdonTeck reconstruida en limpio (sep-2026). Conserva Firebase, Railway, Stripe y Bunny del club actual.

- `index.html` · página de muestra del sistema de diseño (v0.1)
- `src/styles/tokens.css` · colores, tipografía, espaciado (claro por defecto, oscuro con `data-theme="dark"`)
- `src/styles/components.css` · componentes base
- `public/brand` · logo (claro/oscuro) e isotipo

```bash
npm install
npm run dev
```
